# סקרנות · Sakranut

מה השתנה בקריאה בוויקיפדיה העברית — ומה נשאר מעל הרגיל לאורך כמה ימים?

סקרנות מציגה נתוני צפייה יומיים, משווה כל ערך לרמת הקריאה הרגילה שלו, ומפרידה בין המדידה לבין הסברים אפשריים. זו אינה מדידת דעת קהל, פילוח של תושבי ישראל או הוכחה לסיבת הזינוק.

## מה אפשר לעשות

- לגלות קפיצות ביחס לבסיס, את הערכים הנקראים ביותר ועניין מתמשך.
- לפתוח גרף ופירוט לכל ערך, ואז לחזור לאותו חיפוש, מיון ומיקום ברשימה.
- לקרוא 14 ימים בגרף ובטבלה נגישה; סדרות חלקיות מוצגות בלי מדדי השוואה מומצאים.
- לבדוק מקור, תאריך, כיסוי וסטטוס איסוף, או להשהות עדכוני תצוגה.
- לקרוא הקשר מתוארך עם מקורות כשהוא נבדק ואושר. לא לכל זינוק יש הסבר.

## מצב נוכחי

- הקוד נמצא בריפו עצמאי זה; האתר והאיסוף הקיימים נשארים בגישה פרטית בשרת Linux.
- נאסף יום מלא לפי UTC. מתבצעת בדיקה כל שלוש שעות; אחרי פרסום אותו יום, בדיקות נוספות אינן אוספות שוב את המדידה.
- הדפדפן בודק עדכון מדי שעה כשהוא גלוי ובחזרה ללשונית. אלה נתונים יומיים, לא צפיות בזמן אמת.
- איסוף המדידות ממשיך כשהמחשב סגור. הגישה המקומית ב־5175 תלויה במנהרת SSH פתוחה.
- פיילוט ההקשרים כלל מחקר ידני ראשון. הכיוון הנבדק כעת הוא התאמת מטא־דאטה ולוח חגים באמצעות כללים, ללא מודל או סוכן בזמן הריצה. אין עדיין חיפוש עצמאי מתוזמן או פרסום הסברים אוטומטי.
- הקוד ציבורי; זו אינה החלטה לפרסם את האתר או לאפשר שימוש בשירות בתשלום.

## הפעלה מקומית

Node.js 24 נדרש, כמצוין ב־`.nvmrc`.

```bash
npm ci
npm run dev
npm test
npm run build
```

תצוגת הפיתוח: `http://127.0.0.1:5176/`. היא נפרדת מהאתר הפרטי ב־5175 ומן הניסויים הישנים.
`npm run preview` מציג בנייה מקומית בפורט 4176.

`public/data/snapshot.json` הוא צילום הדגמה **אמיתי ומתוארך**, לא הבטחה לנתונים טריים אחרי clone.
בלי `status.json` מאומת התצוגה המקומית מסומנת כצילום ידני.
לעדכון ידני מקומי בלבד: `npm run collect -- --date YYYY-MM-DD` עבור יום מלא. הפקודה מחליפה את צילום הנתונים המקומי; היא אינה מפרסמת לשרת.

## פיילוט הקשר לזינוקים

```bash
npm run context:queue
npm run context:validate -- --input data/context-pilot/YYYY-MM-DD/drafts.json
npm run context:daily -- prepare --snapshot /absolute/path/to/latest-snapshot.json
npm run context:daily -- complete --date YYYY-MM-DD
```

התור כולל עד חמישה ערכים עם עניין מוגבר שניתן לחשב. הוא אינו הסבר ואינו מבצע חיפוש ברשת.
כל התוצרים נשמרים ב־`data/context-pilot/`, המוחרגת מגיט ואינה מוגשת באתר.
בדיקת טיוטה מאמתת מבנה ועקביות, **לא** את אמיתות הכתבה או הסיבה לשינוי בצפיות.

[פרוטוקול הפיילוט](docs/CONTEXT_PILOT.md) מפרט את עבודת האיתור והבקרה ואת התנאים הנדרשים לפני הפעלה מתוזמנת.
אין פקודת פרסום: הכותב אינו רשאי לאשר בעצמו את הטיוטה.

`context:daily` מוסיף בקרת ריצות: יום מדידה טרי, מניעת מחקר חוזר ועצירה אחרי שבעה ימי מחקר שהושלמו. `complete` מתעד השלמת מחקר בלבד, לא אישור עריכתי או פרסום. אין בפקודות חיפוש, מודל או מתזמן; יש לספק להן צילום עדכני מהאוסף, לא להניח שדוגמת הנתונים בגיט התעדכנה.

### ניסוי ללא AI: קישורים קשורים ולוח חגים

```bash
npm run context:related -- benchmark --date YYYY-MM-DD
npm run context:related -- probe --date YYYY-MM-DD
```

הפקודות דורשות תור קיים ב־`data/context-pilot/YYYY-MM-DD/`. `benchmark` דורש גם את הטיוטות הקודמות, ומשחזר התאמה לכותרות שכבר נמצאו ידנית — זו **אינה** בדיקת גילוי אוטומטי. `probe` מבצע בקשה אחת ל־Hebcal; ניסוי גילוי דרך GDELT דורש `--discovery` מפורש. אין הורדה של גופי כתבות, קריאת מודל או חיוב בשירות AI.

התוצאות נשמרות בנפרד ב־`data/related-coverage/`, מוחרגות מגיט ולא מוצגות באתר. הרצה חוזרת משתמשת בתוצאה השמורה, גם כשמקור נכשל, ואינה מבצעת בקשות נוספות. [שיטת הניסוי, המקורות והמגבלות](docs/RELATED_COVERAGE_PILOT.md).

בדיקת המקורות הנוספת לא סיפקה גילוי חדשותי שימושי: GDELT החזיר הגבלת בקשות, וויקיחדשות לא החזיר מועמדים לחמשת הנושאים שנבדקו. הרחבת הגילוי החדשותי מוקפאת כרגע; איסוף ויקיפדיה והאתר הקיים ממשיכים ללא שינוי. זו מסקנת ניסוי מוגבל, לא קביעה שכל חלופה חינמית אינה אפשרית.

הצעת הרצת Codex בשרת אינה המסלול הנבחר; לא הותקן סוכן ולא חובר חשבון לצורך פיילוט ההקשרים.

## מבנה

- `src/` — ממשק עברי RTL, תצוגת מדידות, רענון והקשר.
- `collect.mjs`, `data-lib.mjs` — איסוף וחשבונות מדידה.
- `run-daily.mjs`, `runtime-lib.mjs`, `health.mjs` — הפעלה יומית ובדיקות בריאות.
- `public/data/` — צילום מדידה והקשרים שכבר אושרו.
- `scripts/` — כלים לפיילוט טיוטות.
- `test/` — בדיקות יחידה, ממשק, ריצה ופריסה.
- `ops/wiki-interest/` — פריסה פרטית והוראות שחזור; שמות השירותים הקיימים נשמרו במכוון.

## שיטה, גבולות ופריסה

הבסיס הוא חציון 28 ימים שלפני שבוע הסיווג. נתונים חסרים אינם מושלמים לאפס.
הדגימה מתחילה ברשימת הנצפים ביותר, ולכן אינה מזהה בהכרח כל זינוק בערכים קטנים.
הנתונים הם צפיות, לא מספר אנשים, וכותרות בעברית אינן מזהות מיקום גאוגרפי.
