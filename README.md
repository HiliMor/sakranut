# סקרנות · Sakranut

מה השתנה בקריאה בוויקיפדיה העברית — ומה נשאר מעל הרגיל לאורך כמה ימים?

סקרנות מציגה נתוני צפייה יומיים, משווה כל ערך לרמת הקריאה הרגילה שלו, ומפרידה בין המדידה לבין הסברים אפשריים. זו אינה מדידת דעת קהל, פילוח של תושבי ישראל או הוכחה לסיבת הזינוק.

## מה אפשר לעשות

- לקבל סקירה מרוכזת של הגרף המוביל והשינויים היומיים, ולסרוק את שאר הערכים ברשימת השוואה קומפקטית.
- לבחור יום שנשמר בארכיון, לעבור בין ימים זמינים ולחזור במפורש לנתונים האחרונים. עדכון אוטומטי אינו מחליף יום היסטורי שנבחר.
- לזהות ערכים בעזרת תיאור קצר בעברית מוויקינתונים, כשיש כזה. זהו זיהוי הערך, לא הסבר לזינוק.
- לגלות קפיצות ביחס לבסיס, את הערכים הנקראים ביותר ועניין מתמשך.
- לקבל מבט שבועי: מה עדיין מעל הרמה הרגילה ומה עלה ואז נרגע, גם בערכים שכבר יצאו ממובילי היום. אלה דפוסי צפייה, לא הסברים סיבתיים.
- לקרוא עד שלושה שינויים יומיים בולטים: העליות והירידות הגדולות במספר הצפיות במדגם, בין יום הנתונים לקודמו.
- לפתוח גרף ופירוט לכל ערך, ואז לחזור לאותו חיפוש, מיון ומיקום ברשימה.
- לפתוח חיפוש כתבות חיצוני סביב יום המדידה. זהו כלי לבדיקה עצמאית, לא הסבר שנבדק או איסוף אוטומטי.
- לקרוא 14 ימים בגרף ובטבלה נגישה; סדרות חלקיות מוצגות בלי מדדי השוואה מומצאים.
- לבדוק מקור, תאריך, כיסוי וסטטוס איסוף, או להשהות עדכוני תצוגה.
- לקרוא הקשר מתוארך עם מקורות כשהוא נבדק ואושר. לא לכל זינוק יש הסבר.

## מצב נוכחי

- ב־3 באוקטובר נפרסה בשרת הפרטי איטרציית ההיסטוריה והמעקב: 30 ימים מ־3 בספטמבר עד 2 באוקטובר, עם 400 ערכים שונים. 28 ימים הובאו בדיעבד מה־API הרשמי; שני הצילומים המקוריים והצילום היומי נשמרו ללא שינוי. המבט השבועי כולל גם ערכים שיצאו ממובילי היום. פרטי האימות ב־[מדריך התפעול](ops/wiki-interest/README.md).
- הקוד נמצא בריפו עצמאי זה; האתר והאיסוף הקיימים נשארים בגישה פרטית בשרת Linux.
- האתר הפרטי ב־`http://127.0.0.1:5175/` מציג את נתוני השרת. באימות הפריסה היום האחרון היה 2 באוקטובר, הארכיון כלל 30 ימים וסטטוס האיסוף היה תקין. תיאורי זיהוי מוויקינתונים נוספים בהדרגה, במטמון ובבקשות מוגבלות; היעדר תיאור אינו היעדר נתוני צפייה.
- נאסף יום מלא לפי UTC. מתבצעת בדיקה כל שלוש שעות; אחרי פרסום אותו יום, בדיקות נוספות אינן אוספות שוב את המדידה.
- הדפדפן בודק עדכון מדי שעה כשהוא גלוי ובחזרה ללשונית. אלה נתונים יומיים, לא צפיות בזמן אמת.
- איסוף המדידות ממשיך כשהמחשב סגור. הגישה המקומית ב־5175 תלויה במנהרת SSH פתוחה.
- פיילוט ההקשרים כולל תור מחקר, בדיקת טיוטות והרצת מחקר ראשונה בסיוע סוכנים. אין עדיין חיפוש עצמאי מתוזמן או פרסום הסברים אוטומטי.
- הקוד ציבורי; זו אינה החלטה לפרסם את האתר או לאפשר שימוש בשירות בתשלום.

אימות האיטרציה: 186 בדיקות עברו מקומית וחמש תלויות Linux דולגו; בסביבת Linux מבודדת עברו 190 ואחת ייעודית למערכת שאינה Linux דולגה. הבנייה עברה. בדיקות דפדפן כללו 30 תאריכים, פירוט ערך שהמשיך במעקב, מקלדת וחזרה, רענון תוך צפייה ביום ישן ותצוגות ברוחבי 1280, 390 ו־320 פיקסלים; אומת גם האתר הפרטי לאחר הפריסה. הרצה חוזרת השאירה את הצילום, הארכיון וקובץ המעקב ללא שינוי. אלה אינן בדיקות קורא מסך מלא או מכשיר פיזי, בדיקת קוראים או הוכחת עדכון ביום עתידי.

## הפעלה מקומית

Node.js 24 נדרש, כמצוין ב־`.nvmrc`.

```bash
npm ci
npm run dev
npm test
npm run build
```

לצפייה בנתונים המתעדכנים בשרת, פתחו את האתר הפרטי ב־`http://127.0.0.1:5175/` כאשר מנהרת SSH מחוברת. [הוראות החיבור](ops/wiki-interest/README.md#private-access).
תצוגת הפיתוח: `http://127.0.0.1:5176/`. היא קוראת קבצים מקומיים ואינה מסונכרנת אוטומטית עם השרת.
`npm run preview` מציג בנייה מקומית בפורט 4176.

`public/data/snapshot.json` הוא צילום הדגמה **אמיתי ומתוארך**, לא הבטחה לנתונים טריים אחרי clone.
בלי `status.json` מאומת התצוגה המקומית מסומנת כצילום ידני.
לעדכון ידני מקומי בלבד: `npm run collect -- --date YYYY-MM-DD` עבור יום מלא. הפקודה מחליפה את צילום הנתונים המקומי; היא אינה מפרסמת לשרת.

## פיילוט הקשר לזינוקים

```bash
npm run context:queue
npm run context:validate -- --input data/context-pilot/YYYY-MM-DD/drafts.json
```

התור כולל עד חמישה ערכים עם עניין מוגבר שניתן לחשב. הוא אינו הסבר ואינו מבצע חיפוש ברשת.
כל התוצרים נשמרים ב־`data/context-pilot/`, המוחרגת מגיט ואינה מוגשת באתר.
בדיקת טיוטה מאמתת מבנה ועקביות, **לא** את אמיתות הכתבה או הסיבה לשינוי בצפיות.

[פרוטוקול הפיילוט](docs/CONTEXT_PILOT.md) מפרט את עבודת האיתור והבקרה ואת התנאים הנדרשים לפני הפעלה מתוזמנת.
אין פקודת פרסום: הכותב אינו רשאי לאשר בעצמו את הטיוטה.

## מבנה

- `src/` — ממשק עברי RTL, תצוגת מדידות, רענון והקשר.
- `collect.mjs`, `data-lib.mjs` — איסוף וחשבונות מדידה.
- `run-daily.mjs`, `runtime-lib.mjs`, `health.mjs` — הפעלה יומית ובדיקות בריאות.
- `reading-products.mjs`, `archive-products.mjs`, `description-products.mjs` — ארכיון מוגש ותיאורי זיהוי אופציונליים, בשכבה נפרדת מהמדידה.
- `backfill.mjs`, `tracking-products.mjs`, `src/tracking-lib.js` — הכנה ויבוא נפרדים של ימים היסטוריים, ומעקב יומי מוגבל אחרי מדגם משתנה.
- `public/data/` — צילום מדידה והקשרים שכבר אושרו.
- `scripts/` — כלים לפיילוט טיוטות.
- `test/` — בדיקות יחידה, ממשק, ריצה ופריסה.
- `ops/wiki-interest/` — פריסה פרטית והוראות שחזור; שמות השירותים הקיימים נשמרו במכוון.

## שיטה, גבולות ופריסה

הבסיס הוא חציון 28 ימים שלפני שבוע הסיווג. נתונים חסרים אינם מושלמים לאפס.
הסיכום היומי נפרד מההשוואה לבסיס: הוא מדרג לפי גודל ההפרש המוחלט בין שתי יממות UTC עוקבות. גם ערך עם היסטוריה חלקית יכול להיכלל אם יש בו שתי מדידות תקינות; אין מכפיל או אחוז שינוי מאפס. התאריכים מוצגים במפורש ואינם נגזרים משעון המחשב. אין הסקת שינוי בדירוג, כניסה לרשימת הנצפים או סיבתיות.
קישור החיפוש נפתח רק בלחיצה, ללא שאילתות רקע. סינון התאריכים של Google מתייחס לעדכון מסמכים, לא בהכרח לפרסום כתבה או למועד האירוע. מקור: [תיעוד חיפוש Google](https://support.google.com/websearch/answer/2466433?hl=en).
הדגימה מתחילה ברשימת הנצפים ביותר, ולכן אינה מזהה בהכרח כל זינוק בערכים קטנים.
הנתונים הם צפיות, לא מספר אנשים, וכותרות בעברית אינן מזהות מיקום גאוגרפי.

הארכיון מציג רק צילומי מצב מאומתים, כולל השלמה בדיעבד מהמקור: לכל יום נלקחת רשימת המובילים שלו וחלון ההשוואה שקדם לו. צילום בדיעבד מסומן `collectionOrigin: retrospective`, עם זמן שליפה אמיתי; צילום קיים אינו מוחלף. אין השלמה לאפס, הורדת סף הכיסוי של 75% או החלפת יום חסר ביום סמוך. ההשלמה היא פעולה מוגבלת ומפורשת, לא משימה מתוזמנת חדשה. צילומי ההיסטוריה הפרטיים אינם מוגשים ישירות: מיוצאים רק שדות מדידה מאומתים לנתיבים מפורשים.

המעקב הנוסף כולל ערכים שהופיעו במדגמי 30 הימים האחרונים, ונמשך עד 30 יום מההופעה האחרונה. סדרות חופפות ממוחזרות; ביום חדש נשלף רק הזנב החסר. בריצה יש עד 80 בקשות עוקבות, ולא מתחילים בקשה נוספת אחרי דקת עבודה; בקשה שכבר התחילה עשויה להשלים לאחר מכן. התור נותן קדימות למדידות הישנות כדי לא להרעיב ערך שנשאר מאחור. `Retry-After` עוצר את התור, נשמר במטמון ודוחה ריצות נוספות. כשל אינו פוגע בצילום היומי, בסטטוס המדידה או בהקשרים מאושרים. הכיסוי המלא של המעקב אינו מובטח בכל ריצה; רק סדרה מלאה עם בסיס מספיק משתתפת בסיווג השבועי.

״ממשיך לבלוט״: לפחות שלושה ימים רצופים מעל סף העניין המוגבר עד היום הנבחר, גם אם קיימת ירידה משיא קודם. ״עלה ואז נרגע״: שיא בשבוע של לפחות פי שלושה מהבסיס ו־500 צפיות, ואחריו שני ימים אחרונים מתחת לסף העניין המוגבר. הבסיס הוא אותו חציון 28 ימים שקודם לשבוע. בכל קבוצה מוצגים עד שני ערכים, לפי סך הצפיות שמעל הבסיס בשבוע. אי־הופעה בדירוג אינה ירידה בצפיות. בבחירת יום ישן לא נכללים ערכים שהתגלו אחריו ולא נעשה שימוש במדידות מאוחרות ממנו. המבט השבועי חל על חלון המעקב האחרון; צילומי הארכיון ממשיכים להישמר גם מעבר לו. [פרוטוקול ההשלמה והמעקב](docs/HISTORY_PATTERNS.md).
תיאורי הזיהוי מגיעים מ־[WikibaseClient של ויקיפדיה העברית](https://he.wikipedia.org/w/api.php?action=help&modules=query%2Bpageterms), לפי כותרת מדויקת ומזהה הישות המקושרת בוויקינתונים. נשלף רק שדה התיאור בעברית, לא גוף הערך; אין חיפוש שם עמום, AI או יצירת תיאור חסר. [נתוני ויקינתונים ברישיון CC0](https://www.wikidata.org/wiki/Wikidata:Licensing).
מטמון שבעה ימים מפחית בקשות; בריצה יש לכל היותר שתי בקשות עוקבות של עד 20 כותרות, עם עדיפות למדגם הנוכחי. כשל, `maxlag` או `Retry-After` שומרים את התיאורים הקיימים ואת המדידות, ודוחים ניסיון נוסף. בפירוט נשמרים מקור וזמן שליפה: תיאור המוצג לצד יום ישן אינו תיאור היסטורי של אותו יום.
